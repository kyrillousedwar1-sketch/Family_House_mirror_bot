# Leech Mirror Telegram Bot

بوت تليجرام متكامل لعمل Leech & Mirror للروابط المباشرة والتورنت، مع ميزة ضغط الفيديوهات تلقائياً باستخدام FFmpeg وتخصيص غلاف الفيديو (Thumbnail) وقائمة أوامر منبثقة (Inline Keyboard).

## طريقة النشر على Railway:
1. ارفع محتويات هذا الملف المضغوط إلى مستودع (Repository) خاص بك على GitHub.
2. اربط حساب Railway بالمستودع.
3. أضف متغيرات البيئة التالية في قسم الـ Variables على Railway:
   - `BOT_TOKEN` : توكن البوت الخاص بك من BotFather.
   - `API_ID` : معرف الـ API الخاص بك من موقع تليجرام الرسمي.
   - `API_HASH` : الهاش الخاص بك.
